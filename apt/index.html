Axiomantic Rhizo APT Repository

Official Debian/Ubuntu package repository for Rhizo (amd64 & arm64 architectures).

Installation via APT

# 1. Add repository to sources
echo "deb [trusted=yes] https://axiomantic.github.io/rhizo/apt/ ./" | sudo tee /etc/apt/sources.list.d/rhizo.list

# 2. Update and install
sudo apt-get update
sudo apt-get install -y rhizo

Homebrew Installation (macOS & Linux)

brew install axiomantic/tap/rhizo

npm Installation (Global)

npm install -g @axiomantic/rhizo

Universal One-Line Installer

curl -fsSL https://raw.githubusercontent.com/axiomantic/rhizo/main/scripts/install.sh | bash

For comprehensive architecture guides, CLI specifications, and wire protocols, visit the Rhizo Documentation Portal or the Rhizo GitHub Repository.
